# Simply Live ⚡
### Autonomous Real-Time Local Services Intelligence Platform

Simply Live is an autonomous real-time neighborhood intelligence platform connecting residents directly with verified local food services, tiffins, express laundromats, and domestic housekeeping across India with **0 middlemen and 0 markups**.

---

## 🌟 Key Features

- **Live Daily Menus & Pricing**: Providers update daily specials, rotating menus, and prices in real time.
- **Strict Dietary Integrity**: 100% verified pure vegetarian kitchens and non-vegetarian specialists are strictly segregated.
- **Autonomous Real-Time AI Concierge**: Built-in AI assistant answers natural language questions, scans live database records, calculates distances, and presents actionable recommendations only when requested.
- **Provider Portal & Live Dashboard**: Service providers can manage their business listing, monitor call/view leads, receive live customer inquiries, and respond in real time.
- **Interactive OpenStreetMap Radar**: Visual map view with active provider filtering and live distance calculation.
- **Progressive Web App (PWA)**: Offline service worker, responsive mobile-first interface, and fast installable app manifest.

## 🚀 Quick Start (Local Development)

### Prerequisites
- Node.js (v18+)
- npm

### Installation
```bash
git clone https://github.com/RaghavDev-cyber/simply-live.git
cd simply-live
npm install
npm start
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

---

## ☁️ Deployment (Free of Cost)

### Deploy to Render.com
1. Go to [Render.com](https://render.com) and create a free account.
2. Click **New +** -> **Web Service**.
3. Select and connect your repository `RaghavDev-cyber/simply-live`.
4. Set Build Command: `npm install`
5. Set Start Command: `npm start`
6. Select **Free** instance type and click **Deploy**.
